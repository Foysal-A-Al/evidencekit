# Local Browser Workbench Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Execute inline as authorized by the user's “do it”.

**Goal:** Deliver a local browser interface for bounded repository inspection, evidence findings, and copyable completion/rebuild prompts.
**Architecture:** Dependency-free Node HTTP service and static browser UI. Collect explicit bounded context; connect a restricted Claude CLI when supported or export/import a schema-bound request/result for existing agents.
**Tech Stack:** Node >=22, browser HTML/CSS/JS, node:test.
**Spec:** docs/superpowers/specs/2026-10-30-local-web-design.md

## Global Constraints
Loopback only; no Python/API key; source read-only; no shell-supplied commands; preserve skill-only install. No universal native-host guarantee.

## Review Focus
- Host/Origin/token attacks must be rejected.
- Local path and symlink traversal must not leave chosen source scope.
- Repo/goal/model text must render as text, not HTML.
- Missing CLI, malformed output, cancellation and limits must surface honest errors.
- GitHub parsing must reject arbitrary network hosts and carry selected refs.
